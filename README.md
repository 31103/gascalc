# gascalc

レセプト（診療報酬明細書）作成時の確認を補助する、酸素・窒素ガス使用量計算ツールです。時刻ごとの流量と、必要に応じてFiO2を入力すると、日ごとの使用量を計算します。

[デモを開く](https://31103.github.io/gascalc/gascalc.html)

## このツールの前提

- 1回の作業では、1つのレセプト月だけを扱います。
- 日番号は実際の暦ではなく、レセプト月内の論理的な`1〜31日`です。現在が2月でも31日を入力できます。
- 月をまたいだ連続計算には対応しません。
- 計算結果はレセプト作成の補助情報です。請求内容の最終判断や、実際のガス供給量の保証を行うものではありません。

## 使い方

### 1. 時刻ごとの条件を入力する

画面下部から次の値を入力し、「追加」を選択します。

| 項目 | 入力 | 例 |
|---|---|---|
| 日付時刻 | `DDHHMM` | 2日9時7分は`20907` |
| 時刻のみ | `HHMM` | 9時7分は`0907`または`907` |
| 流量 | 0以上の数値（L/min） | `1.5` |
| FiO2 | FiO2モード時のみ、21〜100の整数（%） | `40` |

時刻だけを入力した場合、入力リスト内で最も遅い日時の日番号を引き継ぎます。最初の入力で日番号を省略した場合は1日になります。

入力順は問いません。追加後に論理日時順へ並べ替えられます。同じ日時を再度追加した場合は、確認を表示せず、新しい内容で置き換えます。

### 2. 入力内容を確認・修正する

入力リストの各項目から修正または削除できます。修正後の日時が別の入力と重なった場合も、保存した内容で置き換えます。

計算条件に関わる「FiO2モード」または「室内気不使用」を変更すると、それまでの入力と計算結果はクリアされます。

### 3. 結果を利用する

結果は日ごとに表示され、小数第1位へ丸められます。各日のコピーボタンを選択すると、レセプト入力用の文字列をクリップボードへコピーします。

ブラウザの制限で自動コピーが許可されない場合は、「コピーに失敗しました」と表示されます。

## 計算方法

各入力の条件は、次の入力時刻まで継続するものとして計算します。次の入力が別の日の場合は、日付境界で分割してそれぞれの日へ集計します。最後の入力だけは、その日の24時まで計算します。

`Q`を流量（L/min）、`t`を継続時間（分）、`F`をFiO2（%）とします。

| モード | 酸素使用量 | 窒素使用量 |
|---|---:|---:|
| 通常 | `Q × t` | 計算しない |
| FiO2・室内気使用 | `((F - 21) / 79) × Q × t` | 計算しない |
| FiO2・室内気不使用 | `(F / 100) × Q × t` | `((100 - F) / 100) × Q × t` |

室内気使用時のFiO2が21%の場合、追加酸素使用量は0です。

### 計算例

通常モードで、2日8時30分に流量2 L/min、同日10時に流量1 L/minを入力した場合:

- 8時30分〜10時: `2 × 90 = 180 L`
- 10時〜24時: `1 × 840 = 840 L`
- 2日の酸素使用量: `1,020 L`

## 設定とデータ保存

- ダークモード設定だけをブラウザのローカルストレージへ保存します。
- 入力した日時、流量、FiO2、計算結果は保存しません。ページを再読み込みすると失われます。
- ビルド済みHTMLは単一ファイルで、インターネット接続なしでも利用できます。

設定ダイアログはマウス操作に加え、Tabキーによるフォーカス移動とEscapeキーによる終了に対応しています。

## ローカルで利用する

[Releases](https://github.com/31103/gascalc/releases)から`gascalc.html`を取得し、対応ブラウザで開きます。CSS、JavaScript、アイコンフォントはHTML内に含まれています。

## 開発

### 必要な環境

- Node.js 24以上
- npm（`package-lock.json`を使用）

### セットアップと開発サーバー

```bash
npm ci
npm run dev
```

開発サーバーは通常`http://localhost:5173`で起動します。

### 品質チェック

```bash
npm run lint
npm run check
npm test
npm run build
```

`npm run build`は`dist/gascalc.html`を生成します。CIでもLint、Svelte/TypeScript型検査、テスト、ビルド、成果物の存在確認を同じ順序で実行します。

Denoをタスクランナーとして使う場合は、`deno task dev`と`deno task build`も利用できます。依存関係とロックファイルの管理にはnpmを使用してください。

## 主な技術

- TypeScript / Svelte 5
- Vite 8 / vite-plugin-singlefile
- Tailwind CSS 4
- Vitest / Testing Library / jsdom
- Biome / svelte-check
- GitHub Actions / release-please

アプリケーションの中核は、暦やタイムゾーンに依存しない論理日時処理、ガス使用量計算、同一日時の置換処理として分離されています。詳細な開発規約は[CONTRIBUTING.md](CONTRIBUTING.md)を参照してください。
