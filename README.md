# gascalc

レセプト（診療報酬明細書）作成時の確認を補助する、酸素・窒素ガス使用量計算ツールです。時刻ごとの流量と、必要に応じてFiO2を入力すると、日ごと・計算モードごとの使用量を計算します。

[デモを開く](https://31103.github.io/gascalc/gascalc.html)

## このツールの前提

- 1回の作業では、1つのレセプト月だけを扱います。
- 日番号は実際の暦ではなく、レセプト月内の論理的な`1〜31日`です。現在が2月でも31日を入力できます。
- 月をまたいだ連続計算には対応しません。
- 計算結果はレセプト作成の補助情報です。請求内容の最終判断や、実際のガス供給量の保証を行うものではありません。

## 使い方

画面上部の「使い方」から、基本操作と各機能の説明をいつでも確認できます。初めて使用する場合は、画面に表示される「最初の入力を追加しましょう」の案内に沿って入力してください。

### 1. 時刻ごとの条件を入力する

画面下部から次の値を入力し、「追加」を選択します。

| 項目 | 入力 | 例 |
|---|---|---|
| 日付時刻 | `DDHHMM` | 2日9時7分は`20907` |
| 時刻のみ | `HHMM` | 9時7分は`0907`または`907` |
| 酸素流量 | 酸素流量方式で使用する0以上の数値（L/min） | `1.5` |
| 総流量 | 酸素濃度方式で使用する0以上の数値（L/min） | `40` |
| 設定酸素濃度 | 酸素濃度方式で使用する21〜100の整数（%） | `40` |

時刻だけを入力した場合、入力リスト内で最も遅い日時の日番号を引き継ぎます。最初の入力で日番号を省略した場合は1日になります。

日付時刻の入力欄の下には、省略時の対象日や入力内容の解釈が常に表示されます。たとえば対象日が3日のときに`1015`と入力すると、「3日 10:15として追加します」と表示されます。追加する前に、意図した日付時刻になっていることを確認してください。

入力順は問いません。追加後に論理日時順へ並べ替えられます。同じ日時を再度追加した場合は、確認を表示せず、新しい内容で置き換えます。

### 2. 入力内容を確認・修正する

入力リストの各項目から修正または削除できます。修正後の日時が別の入力と重なった場合も、保存した内容で置き換えます。

画面下部の現在方式を示すボタンを押して、「酸素流量から計算」または「総流量・酸素濃度から計算」を選びます。選択エリアは通常は折り畳まれ、入力を追加すると自動で閉じます。後者では、空気の供給元を「室内空気（内蔵コンプレッサー）」または「合成空気（配管）」から選択します。切替は次に追加する入力から適用され、入力済み条件とP/F比の測定履歴は消去されません。入力リストの修正画面では保存済み方式も変更できます。

画面上部の「全クリア」を選択すると、入力、計算結果、P/F比の測定履歴をまとめて消去できます。データがある場合は確認画面が表示され、キャンセルすることもできます。消去した内容は元に戻せません。

### 3. 結果を利用する

結果は日ごと、その中で計算モードごとに分けて表示され、小数第1位へ丸められます。日全体の合計は表示しません。各モードのコピーボタンを選択すると、その日・そのモードのレセプト入力用文字列をクリップボードへコピーします。

コピー形式は、酸素流量方式では `402400+552010/酸素ガス使用量*1`、酸素濃度方式では `404520+233203/窒素ガス使用量+552010/酸素ガス使用量*1` です。室内空気を使用する場合、または窒素ガス使用量が0 Lの場合は、窒素ガス部分を省略して `404520+552010/酸素ガス使用量*1` とします。

ブラウザの制限で自動コピーが許可されない場合は、「コピーに失敗しました」と表示されます。

### 4. P/F比を確認する

画面下部の「P/F比」ボタンを選び、表示された入力画面で測定した日付時刻と次のどちらかを入力します。

- **動脈血 PaO2**: 動脈血ガス分析に記載された酸素分圧（mmHg）
- **SpO2**: 指などに装着するパルスオキシメーターの値（70〜99%）

P/F比の日付時刻でも時刻だけを入力できます。省略される日番号は、直前のP/F比測定日、P/F比測定がなければ入力リスト内で最も遅い日時の日番号、どちらもなければ1日です。入力欄の下に解釈結果が表示されるため、登録前に対象日を確認してください。

その時刻に適用される酸素条件からP/F比を計算します。結果は日ごとのガス使用量と一緒に「計算結果」へ表示されます。PaO2またはFiO2を推定した結果には「概算」と表示され、各結果から修正・削除できます。

静脈血ガス分析のPO2から動脈血PaO2を信頼できる精度で換算することはできないため、P/F比の計算には使用できません。静脈血ガスしかない場合は、同時刻のSpO2を使用してください。

## 計算方法

各入力の流量、FiO2、計算モードは、次の入力時刻まで継続するものとして計算します。次の入力が別の日の場合は、日付境界で分割してそれぞれの日・モードへ集計します。最後の入力だけは、その日の24時まで計算します。

`Q`を流量（L/min）、`t`を継続時間（分）、`F`をFiO2（%）とします。

| モード | 酸素使用量 | 窒素使用量 |
|---|---:|---:|
| 酸素流量方式 | `Q × t` | 計算しない |
| 酸素濃度方式・室内空気 | `((F - 21) / 79) × Q × t` | 計算しない |
| 酸素濃度方式・合成空気 | `(F / 100) × Q × t` | `((100 - F) / 100) × Q × t` |

室内空気使用時の設定酸素濃度が21%の場合、追加酸素使用量は0です。合成空気は酸素21%・窒素79%として請求する前提で、合成空気中の酸素分を純酸素として供給した分と合算して酸素ガス使用量へ計上します。

### P/F比の計算

P/F比は `PaO2 ÷ (FiO2 / 100)` で計算し、整数へ丸めます。SpO2を入力した場合は標準的な酸素解離曲線の近似からPaO2を推定します。SpO2が高い領域や低い領域では推定誤差が大きくなるため、結果は確認補助として扱ってください。

酸素濃度方式では入力された設定酸素濃度を使用します。酸素流量方式では、流量に応じて次の一般的な範囲を線形補間し、該当する投与方法をすべて表示します。

| 投与方法 | 流量 | 推定FiO2 |
|---|---:|---:|
| 室内気 | 0 L/min | 21% |
| 鼻カヌラ | 1〜6 L/min | 24〜44% |
| 酸素マスク | 5〜10 L/min | 40〜60% |
| リザーバー付き酸素マスク | 6〜10 L/min | 60〜95% |

実際のFiO2は患者の呼吸状態や投与方法などで変わるため、流量から求めた値は概算です。この機能は診断や治療判断を目的としたものではありません。

### 計算例

酸素流量方式で、2日8時30分に流量2 L/min、同日10時に流量1 L/minを入力した場合:

- 8時30分〜10時: `2 × 90 = 180 L`
- 10時〜24時: `1 × 840 = 840 L`
- 2日の酸素使用量: `1,020 L`

方式をまたぐ例として、1日8時から酸素流量方式、1日14時から酸素濃度方式・室内空気、2日10時から酸素流量方式を入力した場合、1日は酸素流量方式（8〜14時）と酸素濃度方式（14〜24時）、2日は酸素濃度方式（0〜10時）と酸素流量方式（10〜24時）へ分けて表示します。

## 設定とデータ保存

- ダークモード設定だけをブラウザのローカルストレージへ保存します。
- 入力した日時、流量、FiO2、測定履歴、計算結果は保存しません。ページを再読み込みすると失われます。
- ビルド済みHTMLは単一ファイルで、インターネット接続なしでも利用できます。

設定、使い方、P/F比入力、確認画面は、マウスやタッチ操作に加え、Tabキーによるフォーカス移動とEscapeキーによる終了に対応しています。画面を閉じると、操作前のボタンへフォーカスが戻ります。

## ローカルで利用する

[Releases](https://github.com/31103/gascalc/releases)から`gascalc.html`を取得し、対応ブラウザで開きます。CSS、JavaScript、アイコンフォントはHTML内に含まれています。

## 開発

### 必要な環境

- Node.js 24以上
- npm（`package-lock.json`を使用）

### セットアップと開発サーバー

```bash
npm ci
npm run dev
```

開発サーバーは通常`http://localhost:5173`で起動します。

### 品質チェック

```bash
npm run lint
npm run check
npm test
npm run build
```

`npm run build`は`dist/gascalc.html`を生成します。CIでもLint、Svelte/TypeScript型検査、テスト、ビルド、成果物の存在確認を同じ順序で実行します。

Denoをタスクランナーとして使う場合は、`deno task dev`と`deno task build`も利用できます。依存関係とロックファイルの管理にはnpmを使用してください。

## 主な技術

- TypeScript / Svelte 5
- Vite 8 / vite-plugin-singlefile
- Tailwind CSS 4
- Vitest / Testing Library / jsdom
